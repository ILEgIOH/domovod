# Домовод

Мини-приложение для связи жителей многоквартирных домов и управляющих
компаний. Полностью на Python ([Reflex](https://reflex.dev)) — без
отдельного JS-фронтенда.

## Возможности

**Управляющая компания** (регистрируется сама, email + пароль):
- публикует новости для жителей своих домов;
- добавляет дома и подъезды, получает код приглашения для каждого подъезда;
- начисляет задолженности жителям (ЖКХ и др.) и отмечает их оплаченными;
- запускает сборы денег на подъезд (ремонт, ЖКХ и т.д.) с целевой суммой.

**Житель** (регистрируется по коду приглашения от УК):
- видит новости своего дома;
- общается в чате со соседями своего подъезда (обновляется в реальном
  времени);
- видит свои задолженности;
- видит активные сборы своего подъезда и может внести взнос — открывается
  настоящая (тестовая) оплата через ЮKassa.

**Мультитенантность**: каждая УК видит только свои дома, подъезды, жителей,
новости, долги и сборы — данные разных УК полностью изолированы на уровне
запросов к базе данных.

## Технологии

- [Reflex](https://reflex.dev) — весь стек (backend + frontend) на Python
- SQLite (через SQLModel/SQLAlchemy) — для демо; можно заменить на Postgres
  через `DATABASE_URL`
- [ЮKassa](https://yookassa.ru) — приём платежей за сборы. По умолчанию
  используются публичные тестовые реквизиты ЮKassa (sandbox-режим, работает
  «из коробки» без регистрации магазина) — оплата открывается по-настоящему,
  но деньги не списываются. Тестовая карта: `5555 5555 5555 4444`, срок
  `12/30`, CVC `000`.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
reflex run --env prod --single-port
```

Приложение откроется на http://localhost:3000

Для разработки с горячей перезагрузкой используйте `reflex run` (без
`--env prod`).

## Переменные окружения

См. [.env.example](.env.example). Все переменные необязательны — без них
приложение работает с тестовыми реквизитами ЮKassa и локальной SQLite.

## Деплой на Render (бесплатно)

1. Создайте репозиторий на GitHub и запушьте туда содержимое этой папки.
2. На [render.com](https://render.com) → New → Blueprint → укажите репозиторий.
   Render подхватит `render.yaml` и создаст веб-сервис автоматически.
   (Либо вручную: New → Web Service → Runtime: Python → Build Command:
   `pip install -r requirements.txt` → Start Command:
   `reflex run --env prod --single-port --frontend-port $PORT`.)
3. Дождитесь окончания билда (несколько минут — Reflex собирает фронтенд).
4. Готово — Render выдаст публичный URL вида `https://domovod-xxxx.onrender.com`.

**Важно про бесплатный тариф Render:**
- сервис «засыпает» при отсутствии запросов ~15 минут — первый заход после
  паузы займёт ~30–50 секунд;
- файловая система эфемерна — база данных SQLite **сбрасывается** при
  каждом передеплое/перезапуске контейнера. Для демо это не проблема
  (можно каждый раз заново зарегистрировать УК/жителя), но для реального
  использования переключитесь на управляемую Postgres (Render Postgres
  free tier) через переменную `DATABASE_URL`.

## Известные ограничения демо-версии

- **Интеграция с платформой MAX**: это готовое веб-приложение с мобильным
  интерфейсом, которое можно открыть по прямой ссылке в браузере (в том
  числе с телефона) — так и тестируются мини-приложения на этапе
  разработки. Официальная публикация как мини-приложения именно в MAX
  требует регистрации приложения в кабинете разработчика MAX и встраивания
  через их SDK — это отдельный шаг, для которого нужен ваш аккаунт
  разработчика MAX.
- Чат обновляется опросом раз в ~2.5 сек (а не по WebSocket-подписке между
  пользователями), для нескольких участников этого достаточно для демо.
- Платежи — в тестовом режиме ЮKassa. Для приёма реальных денег зарегистрируйте
  свой магазин в ЮKassa и укажите `YOOKASSA_SHOP_ID`/`YOOKASSA_SECRET_KEY`.
